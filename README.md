# Котокафе — idle-игра для Яндекс Игр

Код игры — один файл `index.html` (чистые HTML, CSS и JS, без сборки и внешних библиотек).
Графика — спрайты в папке `img/` (WebP, около 450 КБ на всю игру).

## Структура

| Папка / файл | Что это | Нужно для игры |
|---|---|---|
| `index.html` | вся игра | да |
| `img/` | сжатые спрайты, их загружает игра | да |
| `sprites/` | исходные PNG в полном размере (около 19 МБ) | нет |
| `tools/build_sprites.py` | собирает `img/` из `sprites/` | нет |

## Запуск

- **Локально:** выполните `python3 -m http.server` в папке проекта и откройте `http://localhost:8000`.
  `/sdk.js` не найдётся, и игра сама перейдёт на заглушки: реклама показывается
  окном «Реклама (заглушка)», сохранения идут в `localStorage`.
  С параметром `?debug` в консоли доступен объект `CatCafe` для отладки.
- **Яндекс Игры:** загрузите zip-архив, в котором лежат только `index.html` и папка `img/`.
  Папку `sprites/` в архив не кладите. Платформа сама отдаёт `/sdk.js`.

## Спрайты

Исходники лежат в `sprites/`. Чтобы пересобрать сжатые версии:

```
pip install pillow numpy opencv-python-headless
python3 tools/build_sprites.py
```

Скрипт обрезает прозрачные поля, уменьшает картинки и сохраняет их в WebP:
персонажей до 256 px, иконки до 128 px, монету и звезду до 96 px, фоны до 720×1080.
Из иконки «Улучшение кофемашина» он делает чистую кофемашину без стрелки и искр:
это главный объект для тапа (`img/machine.webp`).

**Новый спрайт:** положите PNG в `sprites/`, добавьте строку в `SPRITES` в скрипте,
запустите скрипт и пропишите путь `img/<имя>.webp` в поле `icon` нужного элемента `CONFIG`.

**Новый гость коллекции:** спрайт, строка в `CONFIG.guests.list` и имя в `I18N.ru.guests` и `I18N.en.guests`.

## Где что менять

- `CONFIG` в начале скрипта: баланс, сотрудники, улучшения, гости, достижения,
  города (фон, фильтр и цветовая накладка), офлайн, ежедневные награды, реклама.
- `I18N`: все тексты на русском и английском. В любом тексте можно писать `{coin}`,
  `{star}` и `{ad}` — на их место встанут картинка монеты, звезды или значок рекламы.
