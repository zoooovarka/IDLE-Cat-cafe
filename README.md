# Котокафе — idle-игра для Яндекс Игр

Весь код в одном файле `index.html`: чистые HTML, CSS и JS, без сборки и внешних библиотек.

## Запуск

- **Локально:** `python3 -m http.server` в папке проекта, затем откройте `http://localhost:8000`.
  `/sdk.js` не найдётся, и игра сама перейдёт на заглушки: реклама показывается
  окном «Реклама (заглушка)», сохранения идут в `localStorage`.
  С параметром `?debug` в консоли доступен объект `CatCafe` для отладки.
- **Яндекс Игры:** загрузите архив с `index.html` в консоль разработчика.
  Платформа сама отдаёт `/sdk.js`.

## Где что менять

- `CONFIG` в начале скрипта: баланс, сотрудники, улучшения, гости, достижения,
  города, офлайн, ежедневные награды, параметры рекламы.
- `I18N`: все тексты на русском и английском.
- Поле `icon` (и `badge`) принимает эмодзи или путь к картинке (`img/cat.png`).
  Картинка подставится автоматически. Для кофемашины есть `CONFIG.machine.image`,
  для фона зала в каждом городе — `bg`.
